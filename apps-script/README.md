# הקמת יומן משותף למשפחה (Google Sheets)

**רוב המשפחות לא צריכות את זה.** אם באתר מופיע כפתור "✨ יצירת יומן משפחתי" – לוחצים עליו ושולחים את קישור ההצטרפות. ההוראות כאן הן:
- **למפעיל האתר** – הקמה חד-פעמית של השרת המשותף לכל המשפחות (ראו "שרת משותף" בסוף), או
- **למשפחה שרוצה שהנתונים יהיו בגיליון בבעלותה.**

פעם אחת, כ-5 דקות, ממחשב.

## 1. גיליון + סקריפט
1. פותחים גיליון חדש: https://sheets.new (אפשר לקרוא לו "מד מים חמים").
2. בתפריט: **Extensions → Apps Script** (תוספים → Apps Script).
3. מוחקים את מה שיש בקובץ `Code.gs` ומדביקים במקומו את כל התוכן של
   [`Code.gs`](Code.gs) מהתיקייה הזו. שומרים (Ctrl+S).

## 2. יצירת מפתח
1. למעלה בחלון העורך בוחרים בפונקציה **`setup`** ולוחצים **Run** (הפעלה).
2. Google יבקש הרשאה – מאשרים (Advanced → Go to … (unsafe) – זה הסקריפט שלכם, הוא ניגש רק לגיליון הזה).
3. ב-**Execution log** תופיע שורה `KEY: …` – מעתיקים את המפתח.

## 3. פרסום כ-Web App
1. **Deploy → New deployment** (פריסה חדשה).
2. בגלגל השיניים בוחרים **Web app**.
3. **Execute as: Me**, **Who has access: Anyone**.
4. **Deploy** ומעתיקים את ה-**Web app URL** (נגמר ב-`/exec`).

> "Anyone" אומר שכל מי שיש לו את הכתובת **וגם** את המפתח יכול לקרוא ולכתוב. בלי המפתח השרת מחזיר שגיאה.

## 4. חיבור באתר
1. באתר: **🔗 שיתוף עם המשפחה** → מדביקים את הכתובת ואת המפתח → **התחברות**.
   אם כבר רשמתם נתונים בטלפון הזה והגיליון ריק – הם יועלו אליו.
2. לוחצים **📤 שליחת קישור הצטרפות** ושולחים לבני המשפחה (וואטסאפ וכו׳).
   מי שפותח את הקישור מחובר אוטומטית לאותו יומן.

## מה נשמר בגיליון
- `members` – בני המשפחה וכמה ליטר כל אחד צריך (נלמד).
- `logs` – כל המקלחות: מתי, מי, תוצאה.
- `boilers` – הדלקות הדוד החשמלי: מתי ולכמה דקות.
- `config` – הגדרות הדוד (נפח, שטח קולטים, נצילות שנלמדה…).

עדיף לא לערוך את הגיליון ידנית בזמן שמשתמשים באתר.

## עדכון הסקריפט (כשיש גרסה חדשה של `Code.gs`)
1. ב-Apps Script מחליפים את כל התוכן של `Code.gs` בגרסה החדשה ושומרים.
2. **Deploy → Manage deployments** → עיפרון (Edit) → ב-Version בוחרים **New version** → **Deploy**.

ככה הכתובת נשארת אותה כתובת ואין צורך לשנות את `config.js` או לשלוח קישורים חדשים.

## שרת משותף לכל המשפחות (למפעיל האתר)
אותה פריסה בדיוק (שלבים 1–3) משמשת גם כשרת לכל המשפחות:
1. מכניסים את ה-Web app URL לקובץ [`config.js`](../config.js) בשורה `window.HWM_HOSTED_URL = '…';` ודוחפים ל-`main`.
2. מעכשיו באתר מופיע כפתור "✨ יצירת יומן משפחתי". כל לחיצה יוצרת למשפחה **גיליון נפרד ב-Drive שלכם** ומפתח משלה, ונרשמת בלשונית `families` בגיליון הראשי (המפתח נשמר שם רק כ-hash).
3. משפחה רואה רק את הגיליון שלה. אתם, כבעלי ה-Drive, יכולים לראות את כל הגיליונות – כדאי שהמשתמשים ידעו את זה.

מגבלות: עד 50 יומנים חדשים ביום (`MAX_NEW_FAMILIES_PER_DAY` ב-`Code.gs`), וכל הבקשות עוברות בתור אחד, כך שזה מתאים לעשרות משפחות. אם זה יגדל הרבה מעבר – כדאי לעבור לשרת/מסד נתונים ייעודי.

## טופס "צרו קשר" (למפעיל האתר)
הודעות מהדף `contact.html` נשמרות בלשונית `messages` בגיליון הראשי ונשלחות במייל (עם "השב" ישירות לשולח).
- **לאן נשלח המייל:** לחשבון ה-Google שמריץ את הסקריפט. כדי לשלוח לכתובת אחרת: ב-Apps Script → ⚙️ Project Settings → Script properties → מוסיפים `CONTACT_EMAIL` עם הכתובת. (הכתובת לא מופיעה בקוד הציבורי.)
- **הרשאה:** שליחת מייל דורשת הרשאה חדשה. אחרי שמדביקים את `Code.gs` המעודכן – מריצים פעם אחת את `setup` ומאשרים, ואז Deploy → Manage deployments → Edit → New version.
- **הגנה מספאם:** שדה נסתר שרק בוטים ממלאים, הגבלת אורך, ועד 30 הודעות ביום (`MAX_MESSAGES_PER_DAY`).
