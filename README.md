# hotwatermeter

אתר סטטי (קובץ `index.html` אחד) שמושך מ-[Open-Meteo](https://open-meteo.com/) את קרינת השמש השעתית של היום ושל אתמול, ונותן לכל יום ציון 0–100.

## איך מחושב הציון
- `shortwave_radiation` – הקרינה הגלובלית על משטח אופקי (W/m², ממוצע לשעה שקדמה), כך שהעננות כבר נכללת בו.
- "יום בהיר" – קרינת שמיים בהירים, מחושבת לפי מודל Haurwitz ממיקום השמש בכל שעה.
- **ציון = סך הקרינה ביום ÷ סך הקרינה ביום בהיר × 100.**
- היום מוצג גם "עד עכשיו" (רק שעות שעברו) וגם ליום כולו (עם תחזית לשעות שנותרו).

## הערכת הדוד (לכיול)
`ΔT = E × שטח קולטים × נצילות × 3600 / (ליטרים × 4.186)`
כאשר E היא האנרגיה היומית ב-kWh/m². את הנצילות מכיילים לפי מדידות בפועל. ההגדרות והמיקום נשמרים בדפדפן.

## הרצה
פותחים את `index.html` בדפדפן, או מפעילים GitHub Pages על ענף `main` (תיקיית root).
